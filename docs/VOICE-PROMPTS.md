# Voice prompts and tones (Turkish)

The toy talks to the child at the moments where something has to happen or has gone wrong.
Prompts are MP3 files on the SD card, generated by `tools/sounds/gen_prompts.py` (macOS `say`,
voice Yelda) into `sdcard/sounds/`, and played by `VoicePrompts` (src/VoicePrompts.*).

## Card layout

```
/sounds/tr/<name>.mp3     speech, Turkish
/sounds/tr/prompts.json   the texts (reference, version)
/sounds/tone_*.mp3        tones
/sounds/beep.mp3          volume beep
```

Write a card with `tools/sdcard-prepare.sh /dev/diskN` (erases it, FAT32, copies `sdcard/`).
A card without the files works: the toy stays silent and logs `VoicePrompts: cannot play`.
Until the factory writes the cards, a missing pack could also be fetched from the portal
(`/sounds/<lang>/` manifest) on the first connection; not built yet.

## Playback rules

- One prompt at a time, queued (8 deep), the same prompt never twice within its interval.
- A prompt marked *interrupt* pauses a playing story, plays, and the story resumes at the
  same position. Everything else is dropped while a story plays (the story wins).
- `sayBlocking` is used only where the device is about to go away (sleep, WiFi reset,
  battery cutoff).
- Prompts do not change the LED scene (the "playing" scene is for stories).

## Error codes (fruit names)

Spoken inside the prompt and sent to the portal as `device_report.last_error` so support can
map a child's "it said Elma" to a cause. The portal does not store the field yet (next step:
column + show on the hub page).

| code | meaning | prompt |
|---|---|---|
| elma | the figure exists but has no stories | figure_no_content |
| armut | portal unreachable and nothing cached for this figure | figure_offline |
| kiraz | stories could not be downloaded | download_failed |
| üzüm | WiFi password rejected during pairing | setup_failed |
| portakal | provisioned, but no network | wifi_lost |
| karpuz | firmware update failed | update_failed |
| muz | SD card problem (reserved; the toy cannot speak without the card) | LED red |

## Changing a text

Edit `PROMPTS` in `tools/sounds/gen_prompts.py`, run it, rewrite the card. The names must stay
in sync with `kNames` in `src/VoicePrompts.cpp`.
